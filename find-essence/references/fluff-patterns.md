# Fluff patterns

Candidates that usually fail the removal test. Each one still has to be tested in context — a hedge can be essence when confidence is the point.

## Throat-clearing and meta-commentary (function test)
- "It is important to note that", "it should be mentioned", "needless to say"
- "In this section we will", "as mentioned above", "as we can see"
- "At the end of the day", "when all is said and done", "in today's world"
- "Basically", "essentially", "actually", "really" (as filler)
- "I think", "in my opinion" — unless the text must mark this as opinion

## Intensifiers and empty evaluatives (falsifiability test)
- "very", "extremely", "highly", "incredibly", "truly"
- "powerful", "robust", "flexible", "seamless", "cutting-edge", "world-class", "best-in-class"
- "a wide range of", "a variety of", "numerous" — replace with the actual number or cut
- "effectively", "efficiently", "successfully" — unless contrasting with a failure mode

## Redundancy (redundancy test)
- Doubled pairs: "each and every", "first and foremost", "basic and fundamental", "any and all", "null and void"
- Restatement openers: "in other words", "that is to say", "put simply", "to put it another way"
- Closing summaries that repeat the body
- Tautologies: "past history", "end result", "future plans", "advance warning", "completely eliminate", "final outcome"

## Wordy constructions (substitution test)
| Wordy | Essence |
|---|---|
| in order to | to |
| due to the fact that | because |
| in the event that | if |
| at this point in time | now |
| has the ability to | can |
| is able to | can |
| make use of / utilize | use |
| a large number of | many |
| the majority of | most |
| prior to | before |
| subsequent to | after |
| with regard to | about |
| in spite of the fact that | although |
| for the purpose of | to / for |
| there is / there are … that | (restructure around the verb) |

## Nominalizations (substitution test)
Verbs turned into nouns plus a weak verb: "perform an analysis" → "analyze", "make a decision" → "decide", "provide a description" → "describe", "conduct an investigation" → "investigate", "is indicative of" → "indicates".

## Hedges (test scope and confidence carefully)
- "somewhat", "rather", "quite", "fairly", "kind of", "sort of", "arguably" — often filler
- "may", "might", "could", "usually", "typically", "in most cases" — often essence; cut only if the claim is unconditionally true
- Stacked hedges ("it may possibly be the case that") — keep one

## Padding specific to definitions and descriptions
- History or origin ("first introduced in 1998 by…") when the job is to define
- Praise or motivation ("a widely used and beloved…")
- Examples that repeat the definition instead of sharpening a boundary
- Listing properties shared by every member of the category (they don't differentiate)
- Comparisons to unnamed alternatives ("faster than other approaches")

## Passive and impersonal padding
- "It can be seen that X" → "X"
- "X is something that Y" → "X Y"
- "There are three factors that affect" → "Three factors affect"
- "The process of doing X" → "doing X"
